## 捧读是什么

捧读是一款由独立开发者制作的日语语法分析与学习 App，背后的开发者同时也做了另一款广受好评的假名入门应用「50音起源」。

简单说，捧读干的事就是：你粘贴或扫描一段日文进去，它帮你自动断句、标注词性、加振假名（汉字注音），然后把整句话的语义结构用树状图画出来，让你看清楚哪个成分修饰哪个成分。

这功能对初学者来说有点像开挂。

## 核心功能拆开来说

**词性标记**：借助机器学习，离线状态下就能自动断句并用不同颜色区分词性。动词是动词、助词是助词，一眼看清楚。

**语义结构图**：这是捧读最有价值的功能。它能把句子里各个文节之间的修饰关系用树状图呈现出来，哪里是主干，哪里是枝叶，再复杂的长句子也有章可循。日语句子修饰关系复杂，靠纯背解决不了，这个图才是真正帮你建立语感的东西。

**离线工作**：除了翻译和扫描需要联网，词性标记、语义分析、查词、朗读全部可以离线使用。地铁上、飞机上、没信号的地方，照样学。

**AI 自动翻译**：联网状态下支持 AI 翻译，可以用来对照自己的理解和正确答案是否一致——这个对练翻译特别好用。

**内置词库与活用分析**：点任意一个词直接查释义，还能追溯动词活用的原形，不用跑去开别的词典。长按还能加生词本，配合段落收藏，结合上下文记单词。

**互动入门课程**：目前提供 6+ 节入门课，交互式设计，在和 AI 对话的过程中了解日语起源和语法结构。高级版可以解锁全部课程。

**EPUB 阅读器**：支持导入 EPUB 电子书，直接在 App 里边读边分析，把自己喜欢的日文内容当学习素材。

**Safari 扩展**：通过 Safari 分享功能可以直接解析网页日文，随时把看到的内容丢进捧读分析。

这些功能加在一起，让捧读变成了一个可以配合任意内容来学习日语的工具，而不是只能刷它自己准备的练习题。
